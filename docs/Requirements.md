# 雷达P型显示仿真系统 - 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
RadarPPI - 雷达P型显示仿真系统

### 1.2 项目目标
开发一个基于Qt的雷达P型显示(PPI - Plan Position Indicator)仿真系统，实现逼真、美观的雷达扫描效果和目标显示功能。

### 1.3 技术约束
| 约束项 | 要求 |
|--------|------|
| 框架版本 | Qt 5.12.0 |
| 编程语言 | 纯C++ |
| 项目文件 | .pro + .ui + .h + .cpp |
| 交付方式 | Docker容器化 (NoVNC访问) |

---

## 2. 功能需求

### 2.1 核心功能 - 雷达PPI显示

#### 2.1.1 雷达背景
- **同心圆距离环**：绘制多个等距同心圆，标识距离刻度
- **方位刻度线**：绘制360°方位线，每30°一条主刻度，每10°一条副刻度
- **刻度标注**：显示距离和角度数值
- **配色方案**：经典深绿色雷达背景风格

#### 2.1.2 雷达扫描线
- **旋转扫描**：模拟雷达天线旋转，扫描线顺时针连续旋转
- **扫描速度**：可调节（默认6秒/圈 = 10 RPM）
- **扫描余辉**：扫描线经过后产生渐变余辉效果（扇形渐变）
- **扫描亮度**：扫描线头部最亮，尾部渐暗

#### 2.1.3 目标显示
- **目标点**：显示模拟雷达目标（亮点形式）
- **目标余辉**：目标被扫描后产生余辉衰减效果
- **目标数量**：支持显示5-10个模拟目标
- **目标运动**：目标可缓慢移动（可选）

### 2.2 界面布局
- **主显示区**：圆形雷达PPI显示区域（居中）
- **控制面板**：底部/侧边控制按钮区
- **状态栏**：显示当前扫描角度、时间等信息

### 2.3 控制功能
- **启动/停止**：控制雷达扫描的开始和停止
- **速度调节**：调节扫描速度（可选滑块）
- **重置**：重置雷达状态

---

## 3. 非功能需求

### 3.1 性能要求
- 帧率 ≥ 30 FPS，确保扫描动画流畅
- 内存占用 < 200MB

### 3.2 视觉要求
- **美观度**：达到专业级雷达模拟器视觉标准
- **配色**：经典军用雷达绿色主题
- **抗锯齿**：所有图形元素启用抗锯齿
- **渐变效果**：扫描余辉使用径向/角度渐变

### 3.3 代码规范
- 遵循Qt编码规范
- 类命名采用大驼峰
- 适当注释

## 4. 技术架构

### 4.1 文件结构
```
RadarPPI/
├── RadarPPI.pro          # Qt项目文件
├── main.cpp              # 程序入口
├── mainwindow.h          # 主窗口头文件
├── mainwindow.cpp        # 主窗口实现
├── mainwindow.ui         # 主窗口UI设计
├── radarwidget.h         # 雷达显示控件头文件
├── radarwidget.cpp       # 雷达显示控件实现
└── resources.qrc         # 资源文件（可选）
```

### 4.2 核心类设计
| 类名 | 职责 |
|------|------|
| MainWindow | 主窗口，布局管理，控制逻辑 |
| RadarWidget | 自定义Widget，负责PPI绑制和动画 |
| RadarTarget | 目标数据结构 |

### 4.3 关键技术点
- `QPainter` 绑制2D图形
- `QTimer` 驱动动画刷新
- `QConicalGradient` 实现扫描余辉
- `QRadialGradient` 实现目标光晕

## 5. Docker交付规范

### 5.1 容器化策略
采用 **Docker + NoVNC** 方案：
- 基础镜像：Ubuntu + Qt5.12运行时
- VNC服务：TigerVNC
- Web访问：NoVNC (WebSocket转VNC)

### 5.2 访问方式
```bash
docker compose up
# 浏览器访问: http://localhost:6080
```
