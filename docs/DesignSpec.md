# 雷达P型显示仿真系统 - 视觉设计规格

## 1. 设计理念

### 1.1 设计风格
**Military Radar Aesthetic** - 军用雷达美学
- 经典CRT显示器质感
- 深邃的绿色光晕效果
- 科技感与专业感并重
- 夜间作战室氛围

### 1.2 设计关键词
`专业` `科技` `精准` `沉浸` `冷静`


### 4.3 目标点

#### 4.3.1 目标显示
```
形状: 圆形光点
尺寸: 直径 8-12px (根据距离可变)
核心: #00FF41 实心
光晕: QRadialGradient 外扩 6px

目标刷新逻辑:
  - 被扫描线扫过时: 亮度 100%
  - 扫描线离开后: 亮度逐渐衰减
  - 衰减周期: 与扫描周期同步
```

#### 4.3.2 目标余辉衰减
```
时间线 (扫描周期 = 6秒):
  T+0s:   100% 亮度 (刚被扫描)
  T+1.5s:  75% 亮度
  T+3s:    50% 亮度
  T+4.5s:  25% 亮度
  T+6s:    重新扫描刷新
```

## 6. 动效规范 (Animation)

### 6.1 扫描动画
```
旋转方向: 顺时针
默认速度: 6秒/圈 (10 RPM)
刷新率:   60 FPS (16.67ms/帧)
角度增量: 1°/帧 (可调)
```

### 6.2 过渡动画
```
按钮悬停: 150ms ease-out
状态切换: 200ms linear
目标余辉: 持续渐变 (随扫描同步)
```
